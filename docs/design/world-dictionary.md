# Midnight Masquerade: 密書の夜会 - 世界観辞書

## 目的

本作は、仮面舞踏会の一夜に参加者が密書を託し合い、誰が真意を隠しているかを探る、スマホ縦型 1 端末パスプレイの夜会ミステリーである。公開画面に現れる名称、物語、画像、文面は本作独自の宴席と密書の語彙で統一し、プレイヤーが端末を手渡す瞬間まで秘密が守られることを視覚設計の最優先条件とする。

## デザイン意図

### プレイヤー体験

- 人: 隣り合って 1 台の端末を回す 2〜4 人の参加者。次の人へ画面を渡す直前まで、自分だけが密書の内容を見ている。
- 行為: 公開された夜会の進行を読み、手元の密書を 1 通選び、相手へ端末を渡す。
- 感触: 華やかだが油断できない、燭台の光が揺れる深夜の仮面舞踏会。豪奢さよりも秘密を扱う緊張を中心に置く。

### 領域語彙

| 領域 | 採用する概念 |
| --- | --- |
| 場所 | 深夜の舞踏広間、鏡張りの回廊、バルコニー、楽団席、クローク |
| 小道具 | 仮面、封蝋、密書、招待状、真鍮の燭台、羽根ペン |
| 社交 | 入場、名乗り、囁き、乾杯、舞踏、退席、告白ではなく暴露 |
| 謎 | 署名、証言、取り違え、監視、盗み見、沈黙 |
| 時間 | 開宴、深夜、終宴、最後の一曲、消えかけた蝋燭 |

### 色と素材

| 名前 | 色・素材の方向 | 用途 |
| --- | --- | --- |
| 深夜の群青 | 黒に近い濃紺 | 背景の基調、画面の静けさ |
| 葡萄酒色の天鵞絨 | 深いボルドー | カード背面、強調面 |
| 古金の真鍮 | くすんだ金色 | 枠、公開情報、重要な焦点 |
| 封蝋の紅 | 暗い朱赤 | 決定、警戒、封印の印 |
| 蝋燭の象牙 | 温かな薄色 | 本文、カード表、発光の芯 |
| 煙る鏡面 | 青灰色の低彩度反射 | 非活性面、ログ、ロック画面 |

### 固有の印

画面全体の署名要素は「半月状の封蝋印」とする。背景の遠景アーチ、カードの封、HUD の現在手番表示、CTA の押下確定、公開ログの最新行に、同じ半月の切り欠きまたは輪郭を抑制的に反復する。単なる金縁 UI ではなく、密書が手から手へ移るゲームであることを一目で示す印にする。

### 既定表現からの置換

| 避ける既定表現 | 置き換える表現 | 理由 |
| --- | --- | --- |
| 一般的なファンタジーの石造広間 | 群青の舞踏広間と鏡の回廊、揺れる燭光 | 秘密と社交が同居する一夜の舞台を特定する |
| 汎用カードゲームの色分け札 | 封蝋、署名、招待状の紙肌で識別する密書 | 機能を物語上の所作へ接続する |
| アプリ風のフラットなステータスバー | 真鍮の進行札と細い譜面線の公開 HUD | プレイ情報を読みやすく保ちながら宴席に属させる |

## 世界観辞書

### 背景

| 項目 | 採用語彙・表現 | 運用基準 |
| --- | --- | --- |
| 空間 | 深夜の舞踏広間、鏡の回廊、遠景のバルコニー | 盤面の背後に留め、人物の物語絵で操作面を埋めない |
| 光 | 蝋燭の暖光、真鍮に映る細い反射、窓外の群青 | 中央のログと下部カードの可読性を侵食しない |
| 装飾 | 半月の封蝋印、仮面の輪郭、譜面線の細線 | 装飾は周縁へ寄せ、タップ対象と競合させない |
| 奥行き | 低コントラストの壁面、わずかな光層 | 動く背景や強い粒子で秘密情報への注意を散らさない |

### カード

| 項目 | 採用語彙・表現 | 運用基準 |
| --- | --- | --- |
| 呼称 | 密書、封書、手元の一通、開封した文面 | 公開コピーでも同じ呼称を維持する |
| 表面 | 象牙紙、細い真鍮枠、封蝋由来の役割記章 | 情報階層は名称、効果、対象選択の順に読む |
| 背面 | 葡萄酒色の天鵞絨と半月状の封印 | 手渡し中や相手側からカード内容を推測できない均一面にする |
| 選択状態 | 封蝋印が灯る、枠がわずかに暖色化 | 強い拡大や跳ね動作で隣のカードを隠さない |
| 公開された札 | 捨て札ではなく「公開された密書」として中央に積む | 表向きの既知情報であることを明確にする |

### HUD

| 項目 | 採用語彙・表現 | 運用基準 |
| --- | --- | --- |
| 上部公開 HUD | 開宴時刻、現在の手番、残る封書数、公開スコア | 誰が見てもよい情報のみを常設する |
| 中央ログ | 夜会録、最新の囁き、公開された密書の履歴 | 短文を優先し、秘密の手札情報を要約しない |
| 状態表示 | 入場中、選択中、手渡し待ち、終宴 | 操作可能性と一致する動詞で示す |
| 秘密表示 | 手番本人が開いた下部カード面のみ | 手渡し準備へ入った時点で非表示にする |

### ボタンと CTA

| 操作 | 表示文言の基準 | 造形と挙動 |
| --- | --- | --- |
| 手番開始 | `密書を確認する` | 封印をほどく意匠。本人確認後だけカード面を表示する |
| 選択決定 | `この密書を託す` | 封蝋の紅を唯一の主要強調色として使う |
| 端末手渡し | `次の客人へ渡す` | ロック面へ遷移してから手渡しを促す |
| 次手番開封 | `仮面を掲げて開始` | 前手番の秘密が消えている状態でのみ有効にする |
| 履歴確認 | `夜会録を見る` | 二次操作として控えめな真鍮線で示す |

### 演出

| 場面 | 採用する演出 | 避ける演出 |
| --- | --- | --- |
| カード確認 | 封蝋の細い発光が解け、紙面が静かに現れる | 内容が他者に見える長い裏返しアニメーション |
| 決定 | 半月の印が一度だけ押印される | 派手な紙吹雪や連続フラッシュ |
| 公開更新 | 夜会録の最新行が蝋燭色で短く浮き上がる | 中央を覆う長文ポップアップ |
| 手渡しロック | 煙る鏡面に仮面の輪郭が沈み、秘密面を完全に閉じる | カードの残像、名称、色別ヒントの露出 |
| 終宴 | 燭光が一点へ集まり結果を照らす | 世界観に無関係な勝利バナーや祝祭エフェクト |

### 文言

| 種類 | 用いる文調 | 例 |
| --- | --- | --- |
| 操作案内 | 短く、儀礼的で、次の行為が明確 | `一通を選び、相手へ託してください` |
| 公開ログ | 事実を過去形で簡潔に記録 | `銀の仮面が一通を公開した` |
| 秘密案内 | 視線と手渡しに配慮した警告を含む | `あなただけが読めます。確認後は封を閉じてください` |
| ロック面 | 次の人の行為だけを提示 | `端末を渡し、次の客人が仮面を掲げます` |
| 結果 | 暴露と終宴の語彙で締める | `最後の曲が終わり、密書の主が明かされました` |

### 禁止語彙・禁止表現

以下は出自作品を連想させるため、タイトル、ロゴ、カード名、ストーリー、画像内装飾、メタデータ、生成プロンプトの肯定指定に使用しない。

| 禁止対象 | 扱い |
| --- | --- |
| `Love Letter` branding | 名称・ロゴ・箱絵風構図・作品識別要素として採用しない |
| `姫` | 登場役割、勝敗文言、画像モチーフに採用しない |
| `王宮` | 舞台名、背景説明、建築モチーフの指定に採用しない |
| 出自作品に固有の役職名・説明文 | 機能が同等でも、本作の密書と夜会の文面へ書き直す |
| 既存商品を模したロゴ、カード枠、パッケージ構図 | 生成画像、UI 装飾、公開素材のいずれにも持ち込まない |

## 配置制約

### 対象 viewport と安全域

| Viewport | 水平方向の安全余白 | 下部操作域の方針 | 確認重点 |
| --- | --- | --- | --- |
| `390x844` | 左右各 `16px` 以上 | 2 枚の密書と主 CTA が片手操作圏に収まる最小基準 | カード面と CTA の縦方向競合、ログの圧迫 |
| `430x932` | 左右各 `18px` 以上 | 余剰高は中央の呼吸とカード説明可読性へ配分 | 装飾拡大による情報密度の崩れ |

`safe-area-inset-top` と `safe-area-inset-bottom` が存在する端末では、上下の固定面は必ず inset の内側に置く。高さの余剰を理由に秘密表示の範囲を拡張せず、公開・秘密・操作の三層構造を両 viewport で維持する。

### 縦方向の情報層

| 層 | アンカー関係 | 表示できる情報 | 制約 |
| --- | --- | --- | --- |
| 上部公開 HUD | 画面上端の安全域直下に固定 | 現在の手番名、進行、残数、公開スコア | 手札名、引いた札、選択候補を置かない |
| 中央ログ / 公開された密書 | 上部 HUD 下端と下部カード上端の間に確保 | 夜会録の最新履歴、表向きにされた密書 | 下部カードへ被らず、最新行が判読可能な最小高さを維持する |
| 下部手札 2 枚 | CTA の直上へアンカーし、同一行で並べる | 手番本人だけが読む 2 通の密書 | `cardWidth <= (usableWidth - cardGap) / 2` を守り、右端・下端のはみ出しを禁止する |
| 下部 CTA | 下端安全域の直上に固定 | 現在実行できる一つの主要操作 | カード選択前後で文言と活性状態を一致させる |

### 相対位置と余白

- 上部公開 HUD、中央ログ、下部カード / CTA は重ならない独立した帯として扱い、カード説明の実寸を確認してから中央ログの表示行数を決める。
- 2 枚のカードは均等幅とし、カード間の視認可能な gap を維持する。長い効果文はカード高さを無制限に増やさず、本文の短文化または詳細面への切り替えで扱う。
- CTA は選択中のカードと視覚的に連続させるが、押下領域はカード面と重ねない。誤タップで秘密情報の確認状態が崩れないようにする。
- 中央の公開された密書は、下部の秘密カードより彩度とコントラストを抑え、情報の公開性を保ちながら現在の意思決定を邪魔しない。
- 実装確認では、カード 2 枚と CTA の `bottom` / `right` がそれぞれの親境界内に収まり、中央ログの最下行がカード上端を越えないことを数値で検査する。

### 手渡しロック

- `次の客人へ渡す` を確定した瞬間に、手札 2 枚、選択状態、カード名称、効果文、選択対象の手掛かりを画面から消す。
- ロック面に表示できるのは、作品名、仮面の中立装飾、手渡し案内、次手番を開始する CTA、および既に全員へ公開済みと定義された進行情報だけである。
- ロック面の背景、色、動きから直前のカード種類や選択結果を推測できないよう、毎手番で同一の中立表現を使う。
- 復帰操作では前手番の画面を一瞬も再表示せず、新しい手番の本人確認を経た後にのみ秘密カード面を開く。

## Image gen プロンプト要約

### 肯定指定

スマホ縦画面向けの独自ゲーム UI 用ビジュアルとして、深夜の仮面舞踏会、群青の舞踏広間、葡萄酒色の天鵞絨、古金の真鍮、暗い封蝋、暖かな燭光、鏡の回廊、半月状の封蝋印を用いる。華やかな社交の奥に密書をめぐる緊張を感じさせ、中央の公開ログ領域と下部のカード / CTA 領域には静かな可読余白を残す。人物を主役にせず、背景と小道具がゲーム画面を支える構図にする。

### 除外指定

画像内にタイトル、ロゴ、カード名、説明文、数字、読める文字を焼き込まない。`Love Letter` branding、`姫`、`王宮`、既存商品の役割名、既存カード枠や箱絵を思わせる構図、特定作品の識別要素を避ける。下部の操作面に重なる強い装飾、秘密カードを推測させるロック面の差分、眩しい粒子や過度な発光も避ける。
