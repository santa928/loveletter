# Asset Provenance

`Midnight Masquerade: 密書の夜会` の視覚素材は、2026-05-27 に Codex の built-in Image gen を用いて本作専用に生成した独自画像である。

## 表現境界

- 出自作品のロゴ、カード文面、役職名、図版、商品パッケージは入力参照にも出力素材にも使用していない。
- 画像にはゲーム中に変化するカード名、位階、効果説明、プレイヤー名、得点を焼き込まず、HTMLで表示する。
- 生成プロンプトでは、王室・王宮・姫・王冠・紋章および既存ボードゲームの識別要素を明示的に除外した。

## 生成アセット

| ファイル | 用途 | 目視判断 |
| --- | --- | --- |
| `reference/game-screen-reference.*` | 実装基準画面。公開ゲーム画面の配置参考 | 構図のみ採用。封蝋の花形意匠は実素材へ転用しない |
| `title-ballroom.*` | タイトル背景 | 採用。文字と識別ロゴの混入なし |
| `handoff-sealed-letter.*` | 手渡しロックの中心画像 | 採用。抽象仮面の封蝋で秘密保持画面に適合 |
| `card-back.*` | 非公開カード背面 | 採用。均一な背面表示に利用 |
| `card-frame.*` | 表カードの装飾殻 | 採用。中央と下部はHTML情報の配置面として残す |
| `victory-ballroom.*` | ラウンド/マッチ結果背景 | 採用。中央テーブル上へHTML結果を配置する |
| `roles/rank-1-gatekeeper.*` | 門番 | 採用 |
| `roles/rank-2-informant.*` | 情報屋 | 採用 |
| `roles/rank-3-duelist.*` | 決闘士 | 採用 |
| `roles/rank-4-attendant.*` | 仮面の侍女 | 採用。公開文言は独自役職名のみをHTML表示する |
| `roles/rank-5-director.*` | 演出家 | 採用 |
| `roles/rank-6-merchant.*` | 交換商 | 採用 |
| `roles/rank-7-steward.*` | 総支配人 | 採用 |
| `roles/rank-8-host.*` | 夜会の主 | 採用。王族ではなく夜会主催者として表示する |

## 配信用処理

- Image genのPNG出力を生成マスターとして目視確認する。
- アプリではDocker内の画像変換で生成したWebPを参照し、初期表示の重量を抑える。
- PNG生成マスターを公開ディレクトリに残す場合は配信物へ含まれない位置へ移すか、公開前に整理する。
