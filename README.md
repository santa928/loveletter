# Midnight Masquerade: 密書の夜会

スマートフォン1台を順に手渡して遊ぶ、2〜4人向けの短時間カードゲームです。
仮面舞踏会に招かれた客として、協力者へ託した密書を守りながら夜会の主へ届けます。

初版は基本16枚の短時間推理ゲームとしての手触りを優先し、タイトル、役職名、説明文、画面、画像は公開用の独自表現で制作しています。

## 現在の実装

- 2〜4人の設定、任意の名前入力、空欄時の `プレイヤー1` 形式の補完
- 1ラウンド勝負と3点先取戦
- 端末受け渡しロック、本人による開封、補充、カード使用、対象/宣言選択
- 8役職の基本効果、秘密確認、強制退出、ラウンド判定、得点と次開始者引継ぎ
- `情報屋`、`交換商`、本人への `演出家` で必要な一時秘密表示と閉鎖操作
- 途中状態の端末保存と、再表示時に秘密を直接露出しないロック復帰
- GitHub Pages の `/loveletter/` サブパス向け build とモバイル E2E

公開盤面の捨て札表示、操作音/祝福演出の仕上げ、公開用アセットの最終整理、GitHub Pages への実公開は継続作業です。

## 遊び方

1. `夜会へ入る` を押し、人数、名前、対戦形式を設定します。
2. 表示された招待客へ端末を渡し、本人だけが `密書を開封する` を押します。
3. 手札を確認して `密書を一枚引く` を押し、二枚のうち一枚を使用します。
4. 必要に応じて対象または宣言する役職を選びます。
5. 秘密確認画面が出た場合は、本人だけが内容を確認し、`確認して閉じる` を押してから端末を渡します。
6. ラウンド結果を全員で確認します。3点先取戦では勝者から次ラウンドを開始します。

秘密情報が表示されている間は端末を他の参加者に見せないでください。再読込した場合も、進行中の秘密画面は受け渡しロックを挟んで再開します。

## 開発と検証

開発サーバ、テスト、ビルドは Docker コンテナ内で実行します。

```bash
docker compose run --rm --service-ports app npm run dev -- --host 0.0.0.0
docker compose run --rm app npm test
docker compose run --rm app npm run build:pages
docker compose run --rm app npm run test:e2e
```

`build:pages` は GitHub Pages 用にベースパスを `/loveletter/` として静的 bundle を生成します。

## 公開方針

- 公開タイトルは `Midnight Masquerade: 密書の夜会` とし、参照元作品のブランド表示は用いません。
- 役職名、効果文、物語、画面装飾、生成画像は本作独自の表現として制作します。
- 初期公開先は GitHub Pages、次段階では Vercel と Supabase を用いた合言葉ルーム方式を設計します。
- オンライン対応や独自の追加ルールは、オフライン初版の完成とプレイテスト後に扱います。

公開前には、設計用の参考画像を配信対象から分離し、公開 bundle に不要な生成マスターや参照素材が含まれないことを確認します。
